## 数字鲁棒性实验

使用 `examples/sample_marked.png`，1600 × 1000，增强档。
攻击方式、参数和逐项结果保存在 `robustness_results.json`。

| 数字处理 | 本次单张虚构样图结果 |
| --- | --- |
| 原始 PNG | 恢复成功 |
| JPEG quality=85 | 恢复成功 |
| 灰度转换 | 恢复成功 |
| 缩到 75% 再恢复尺寸 | 恢复成功 |
| 数字模糊 / 噪声，及给定的亮度 / JPEG 组合 | 恢复成功 |
| 阈值 170 的二值黑白处理 | 恢复失败 |
| 未同步校正的 1° 旋转 | 恢复失败 |
| 扩展白边，直接缩回原尺寸 | 恢复失败 |
| 扩展白边，用精确四角裁回原坐标 | 恢复成功 |
| 未加水印的负对照 | 没有误报为有效水印 |

这是一张样图的一组实验，不能推断其他照片、参数、设备或纸面链路的成功率。
精确坐标恢复也不等于用户手动点选角点的精度。
重新生成样图时使用随机 salt 和编号，因此再次实验的具体结果可能不同。
